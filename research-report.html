Modeling Approaches for the Predictive AI Evaluation Challenge

Headline

Mirror the AIMS lab’s own published pipeline. Truong et al. (ICML 2025; arXiv:2503.13335), authored by Sang Truong on the CS 321M teaching team, implements Rasch IRT + linear probe on Llama-3-8B embeddings for item-cold-start. Reported column-holdout AUC ≈ 0.804 — that’s our target.

Primary pipeline: amortized IRT + content head (Stages 1, 2a, 2b, 3 from the spec). Secondary: local LLM-as-judge (Qwen2.5-7B) as ensemble component. Discipline throughout: temperature scaling + per-round Platt + clip to [0.02, 0.98]. Don’t bother with GNNs, FT-Transformer-from-scratch, LightFM, or 3PL.

Three model families

Family A · primary

Latent factor (IRT) + content head

Fit Rasch (or 2PL) on training response matrix → recover θs and (bi, ai). Train regressor: item text embedding → predicted (b̂, â). At test: lookup θs for known subject, predict (b̂, â) from text, combine via σ(â · (θ̂ − b̂)).

Naturally calibrated. Cleanest report story. Mirrors AIMS reference. Three independent 2025 papers converge on this architecture (Truong et al., Chen et al. arXiv:2510.00844, PSN-IRT arXiv:2505.15055).

Family B · ensemble

LLM-as-judge (logit-based)

Local 7B-class model (Qwen2.5-7B-Instruct preferred). Frame as yes/no, read next-token logits, return p(yes) / (p(yes) + p(no)). Calibrate with Venn-Abers (Giovannotti & Gammerman, COPA 2024).

vLLM-batched: ~30–60s per 1000 calls on L4/A100. Few-shot via labeled examples is a clean ablation for the report. Best framing: ensemble component, not standalone.

Family C · stretch only

Rubric-based demand profiles

Zhou et al. 2025 (arXiv:2503.06378) — 18 cognitive demand rubrics annotated by GPT-4o. Beats raw embeddings on OOD prediction. Requires offline GPT-4o annotation of training items + a local LLM at test time to annotate test items the same way. High implementation cost.

Pursue only if Days 7–9 free up and the IRT path is bottlenecking on item-text features.

Why mirror Truong et al.

  1. The organizers explicitly designed the competition for this pipeline (torch_measure, the §3.4 NCF worked example, the labeling.py adaptive channel).
  2. Naturally calibrated — the IRT logistic is a proper probability model.
  3. Cleanest report story (decomposition into ability × difficulty; explicit Stage 1/2a/2b/3 mapping).
  4. Fastest at inference (linear/MLP after embedding).
  5. Realistic to beat 0.804 column-holdout AUC with calibration discipline + ensembling.

Stop-loss / decision criteria

Make these binding so the meeting decision doesn’t drift:

Day 4

If IRT + content-head validation log-likelihood is below the NCF baseline (Day 2), debug the IRT fit before adding more components.

Day 6 · LLM-judge go/no-go

Go ahead only if (a) IRT pipeline is within 0.05 mean log-likelihood of the leaderboard top, AND (b) we have an engineer with bandwidth. Otherwise deepen IRT (hierarchical priors, benchmark-conditional difficulty, MIRT exploration).

Day 10 · hard gate

Report draft must exist by end of day. Modeling iteration freezes; remaining time is calibration + ensemble tuning + writing.

Calibration recipe

Training-time

Label smoothing (ε = 0.05–0.10) baked into BCE. Optional: focal loss (Mukhoti et al., NeurIPS 2020) reduces ECE vs. plain BCE.

Post-hoc on held-out training fold

Temperature scaling (Guo et al., ICML 2017). Single scalar T optimized via cross-validated log-loss. Avoid isotonic regression at N<100.

Per-round on revealed labels (K=5/category, 25 total)

Default: global Platt on all 25 (raw_score, label) pairs. Always works; low-variance.
Per-category shifts (only if data permits): within each benchmark, fit a per-category temperature only if the bucket has ≥3 of each class. Shrink toward global Platt with a Bayesian prior.
Order: on first predict() call of round, fit calibrators on labeled; cache on module global; pass every subsequent prediction through.

Output guardrail

Clip predictions to [0.02, 0.98]. Avoids catastrophic log(ε) on confident-wrong predictions.
